## 📂 Projetos em destaque

### 🛒 Olist E-Commerce — SQL e Análise de Dados

[![Repositório Olist](https://img.shields.io/badge/Ver_Projeto-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/nerydyego/olist-ecommerce-sql)

Projeto de análise de dados de e-commerce brasileiro utilizando PostgreSQL e SQL, com foco na construção de uma solução analítica.

**Principais atividades:**
- Estruturação de banco de dados PostgreSQL
- Organização de dados nos schemas RAW e Analytics
- Transformação, validação e auditoria dos dados
- Análise exploratória com SQL
- Desenvolvimento de indicadores de negócio

**Próximas etapas:** análise com Python, dashboards no Power BI e aplicação de Machine Learning.
